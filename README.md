# Astro Sandbox

Try publishing and showing Discourse discussions on a plain Astro site. The checked-in project uses Astro adapter version `0.2.0-alpha.21`.

[Open the site](https://astro.sandbox.discussionbridge.dev/) · [Astro setup guide](https://github.com/DiscussionBridge/astro-discussion-bridge) · [Sandbox chooser](https://sandbox.discussionbridge.dev/)

## Preview the source

```sh
npm ci
npm run dev
```
